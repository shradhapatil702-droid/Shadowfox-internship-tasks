# Task 2: Delhi AQI Analysis

## Objective
The goal of this project was to conduct a detailed analysis of the Air Quality Index (AQI) in Delhi by studying pollution trends, seasonal variations, pollutant behavior, and geographical/environmental factors affecting air quality.

## Problem Statement
Delhi faces severe air pollution due to:
- Vehicular emissions
- Industrial pollution
- Construction dust
- Crop residue burning
- Weather conditions
- Population density

This project analyzes AQI patterns and provides insights that can help improve public health initiatives and pollution-control strategies.

## Research Questions
- Which pollutants contribute most to AQI?
- How does AQI vary seasonally?
- What environmental factors affect air quality?
- How do PM2.5 and PM10 influence AQI levels?
- What is the correlation between pollutants and weather conditions?

## Dataset Features
- AQI
- PM2.5
- PM10
- NO2
- SO2
- CO
- O3
- Temperature
- Humidity
- Wind Speed
- Date and Seasonal Information

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Seasonal Trend Analysis
- Statistical Analysis
- Pollutant Distribution Analysis
- Weather Impact Study

## Visualizations Used
- Line Charts
- Bar Graphs
- Histograms
- Heatmaps
- Scatter Plots
- Boxplots

## Key Findings
- PM2.5 is the major contributor to AQI.
- Winter season records the highest pollution levels.
- Monsoon season improves air quality.
- Wind speed negatively correlates with AQI.
- Vehicular and industrial emissions are major pollution sources.
